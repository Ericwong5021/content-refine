# To B 还是 To C：完全不同的游戏

## 你得先搞清楚你赚的是谁的钱

很多人分不清 To B 和 To C 的区别，甚至都不知道自己到底赚的是 To B 的钱还是 To C 的钱。这个问题搞不清楚，后面所有决策都会错。

我在美国的第一份工作，公司做学生租房网站。学生来看房，房东给我们提成。CEO 认为房东是客户，要维护房东关系。但这不是很明显吗——羊毛出在羊身上，真正的客户是学生。学生把钱给房东，房东把钱打给我们。

> 他认为我们的网站应该挂房东想推的房型，我认为我们的网站应该挂学生想要的房型。[1]

Google、Facebook、Meta，所有搜索引擎和社交平台，真正的客户都是用户。因为有足够多、足够黏的用户，商家才愿意在上面打广告。Facebook 要做的平衡是：留住用户，同时在他们身上薅几钱羊毛。

### To B 和 To C 是两套完全不同的逻辑

我讨论创业，一定是 To C 的。因为 To B 最终还是要 To C。

两者的底层差异在哪？**现金流**。To B 要先投人力物力，可能八九个月才签一单，而 To C 每天一睁眼就有钱，源源不断的现金流。做久了 To C 的人，非常不愿意转 To B。

> 中国人一说做生意，马上就是想外贸，然后 To B，整你大的这种。美国人做生意是只想 To C 的，因为 To C 太简单了。[1]

还有一个关键区别：**软件行业卖一个和卖一千个，花的时间是一样的，所以软件适合 To B。但实体行业卖一个和卖一千个，投入完全不同，所以实体当然要 To C。**

很多中国人觉得做大生意就是给沃尔玛供货、进商超。但他们不想想那个账期——两个月账期，等于直接投入两个月的钱。你到底是要赚现金流，还是要赚一个"大客户"的虚名？

### 消费者不懂你的术语，也没有义务懂

To B 和 To C 的沟通方式天差地别。

To B 是把简单的东西复杂化。租一个办公室，要对接大老板、HR、财务、法务，每个人关心的点不同、KPI不同，你得用他们的专业语言证明你专业。To C 恰好相反——把复杂东西简单化，简单到消费者可以转述给别人。

> To C 就是你要能把一个特别抽象的东西，给他当一个小孩讲，讲了之后，他可以去复述给别人。[2]

To B 的交流以逻辑和利益为基点，To C 一定是情感大于逻辑。我越是逻辑松散、情感饱满的视频，流量越大。因为大部分人愿意在情感上受波动，只有少部分人刷抖音还想看干货。

> To C 的广告，一定是情感上把他的痛点给他戳得特别痛，他才愿意看下去。[2]

Steve Jobs 的 iPhone 就是这个逻辑——手机和 MP3 为什么不能合一？先戳痛点，再给解决方案。

这里有一个中国工厂特别爱犯的错误：用 To B 贸易语言卖 To C 产品。你说你质量好，消费者怎么知道什么叫质量好？你说你用什么材料，消费者怎么知道这材料跟他有什么关系？你得说"这材料让你的产品更耐磨、寿命更长"。

> 消费者怎么知道你这材料对他有什么影响、有什么关系呢？你得用消费者的语言给他解释啊。[2]

### To B 的终点一定是 To C

不管什么生意，最终一定要直面消费者。从物物交易到现在，中间链条越来越多——原材料厂、加工厂、生产厂、品牌方，最后才是消费者。你只要不是品牌方、不直面市场，中间所有链路在我看来都是 To B。

为什么互联网公司估值特别高？因为它的 To B 和 To C 都在它手上，商业闭环打通了。左手是用户，右手是广告商。既控制 C 端保证增量，又控制 B 端保证商家花钱。

> 打广告、收租这种形式，是一个特别特别特别赚钱的形式，因为它的商业是闭环的。[3]

蜜雪冰城就是实体版的互联网企业。品牌做起来之后，打通整个供应链。加盟商必须买它的原材料，所以 B 端定价和 C 端消费者都在它手里。这是为什么蜜雪冰城成本控制那么低。

企业扩张不是建一个厂再建十个厂，而是沿产业链上下游走。在链条上占据的环节越多，话语权越大，越赚钱。京东明明做电商，为什么把物流紧紧抓在手里？因为物流是它的下游。

### 打工者的大脑在偷懒

我有一个叔叔，国内做农用机械配件厂，全球 To B 做得很厉害。去年他要在美国做 To C 零售。他的美国总经理——行业几十年老手——非常不支持。当时做了十几年 To B 销售的我，也跟总经理看法一样：不理解。

几个月后我突然意识到，这是两种完全不同的决策路径。

叔叔看到的是：To B 客户只对低价有兴趣，每年几家比价，工厂随时可能被替代。但如果做 To C，现在没人做，你第一个做就是行业第一，就在消费者中占据话语权。拨一部分利润做实验，百利而无一害。

> 从打工者的角度来说，我们一听到老板说要什么，我们第一反应其实是偷懒，就是我们只会去做我们已经熟悉的决策、路径和执行方案。[4]

中国工厂的错误在于：它从来就没有想过自己可以做零售，从来只把自己放在工厂生产者的角度，觉得薄利多销、走大量外贸单就行。它从来没想过——我要去占消费者的市场份额。

一个有品牌的公司去建厂容易，还是一个有厂的人去建品牌容易？答案很明显。这就是为什么出海一定是趋势——中国工厂有生产能力，缺的是品牌和直面消费者的勇气。

做生意之前，先想清楚你做的是 To B 还是 To C。这两个是完全不同的游戏，用错了规则，满盘皆输。
