# 第一人称转写与知识排版规范（纳瓦尔宝典风格）

> 参考《纳瓦尔宝典》（The Almanack of Naval Ravikant）的编纂体例，把博主在大量口播视频、播客中的碎片化表达，按主题熔炼为第一人称认知长文，并保留原话金句引用与视频可溯源体系。

---

## 一、 核心编纂原则

1. **第一人称叙述（The Creator's Voice）**
   - 彻底摒弃第三人称的转述腔（“作者说”、“博主指出”、“在本期视频中”）。
   - 全篇以博主第一人称“我”展开，保留其独特的思考锋芒、认知直觉与说话风格。

2. **跨视频主题熔炼（Thematic Synthesis）**
   - 不单条视频机械翻译，而是把同一个子话题下的 2~4 条视频观点进行结构化缝合。
   - 剔除短视频平台特有的口水话（如“点赞关注”、“评论区告诉我”等），提炼出连贯递进的商业与认知逻辑。

3. **原话金句引用块（Verbatim Pull Quotes）**
   - 对于最具代表性、逻辑最硬核的原声观点，使用 Markdown 引用块高亮：
     ```markdown
     > 主语是发出动作的人，宾语是承受动作的人。一个人对我的看法，那我不是在他的世界里是宾语嘛？[1]
     ```
   - 引用末尾标注方括号数字 `[1]`, `[2]`，对应文末的原视频来源。

4. **结构层级与版式**
   - **H1 标题**：高度凝练、具有反常识张力的主题句（如 `# 你不"是"底层，你"来自"底层`）。
   - **副标题引用**：紧随 H1 下方的哲学定调句（如 `> 别让标签和比较替你定义自己`）。
   - **分隔线**：`---`。
   - **分节标题**：使用 `### 小标题` 引导，层层递进（通常 3~4 个小节）。
   - **文末来源**：必须包含来源附录：
     ```markdown
     ---

     **来源**

     - [1] [视频标题A](https://www.douyin.com/video/1234567890)
     - [2] [视频标题B](https://www.douyin.com/video/0987654321)
     ```

---

## 二、 自动化编译流水线

文章撰写完成后，放置在：
`content-store/<博主ID>/naval-style/<章节ID>/<序号>-<文章名>.md`

运行流水线命令即可自动生成前端可交互数据：
```bash
./cli.py pipeline:compile-articles <博主ID>
```
前端阅读器会自动渲染：
- 顶部主题导读与副标题
- 独特的 `naval-quote` 艺术引用块
- 点击引用标号可直接悬浮查看来源或跳转抖音原视频
